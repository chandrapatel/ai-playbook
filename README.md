# AI Playbook

AI playbook for prompts, rules, and tool configs across coding assistants.

## Rule Files
- `AI-RULES.md`: Base, platform-agnostic engineering rules.
- `AI-RULES.web-development.md`: WordPress/web profile (use with base rules).

## Usage
- General tasks: load `AI-RULES.md`.
- WordPress/web tasks: load both `AI-RULES.md` and `AI-RULES.web-development.md`.

These files are intentionally tool-agnostic and can be adapted to different AI assistants.
